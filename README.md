# Installation
1. Download the [BepInEx](https://builds.bepinex.dev/projects/bepinex_be/791/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.791%2Bb782da4.zip) loader
2. Extract the downloaded archive into the game folder
3. Download the [latest](https://github.com/Egor935/BATIM-Multiplayer/releases/latest/download/BATIM_Multiplayer.dll) version of the mod
4. Place it in the BepInEx\plugins folder
5. Installation is complete, launch the game!
